# Power-BI---UPI-Transaction-per-year
India's Digital Payments Boom: UPI Transactions Dashboard
An interactive Power BI data analytics project examining a full year of UPI (Unified Payments Interface) transaction ecosystems in India, highlighting macro-trends, financial service adoption, and user demographics.

Key Metrics & Overview
**Total Transaction Value:** ₹3.47 Billion (+8.98% MoM growth)
**Total Transactions:** 300K (+8.3% MoM growth)
**Success Rate:** 96.00% (Demonstrating robust infrastructure stability)
**Active User Base:** 108K
*Created by a Data Analyst.*

Tech Stack & Tools
**Data Visualization & BI:** Microsoft Power BI
**Data Modeling & DAX:** Custom measures, calculated columns, and conditional filtering.
**Design Assets:** Custom dark-theme UI with structured KPIs and demographic distributions.

Core Insights & Findings
**Shift to High-Value Services:** Analysis by service category reveals that loans lead transaction values (₹2.5B), proving that users rely on UPI for major financial commitments beyond micro-transactions.
**Demographic Dominance:** Millennials (37.4%) and Gen X (37.3%) anchor the primary user base, indicating deep digital financial integration across active working generations.
**Temporal Patterns:** Weekdays capture the vast majority of transaction volume (71.6%), mirroring daily professional and commercial economic activity.
